QURAN NOOR — ওয়েবসাইট প্যাকেজ

ফাইলসমূহ:
- index.html: কুরআন, বাংলা/ইংরেজি অনুবাদ ও অডিও
- about.html: আমাদের সম্পর্কে
- privacy.html: গোপনীয়তা নীতি
- contact.html: যোগাযোগ (এখানে নিজের ইমেইল বসান)
- ADSENSE_SETUP.txt: AdSense চালুর নির্দেশনা

প্রথমে ZIP extract করে সব ফাইল একসঙ্গে রাখুন। index.html খুললে ওয়েবসাইট চলবে; কুরআনের তথ্য আনতে ইন্টারনেট প্রয়োজন।

GitHub Pages-এ ফ্রি প্রকাশ:
1) github.com-এ সাইন ইন/অ্যাকাউন্ট খুলুন।
2) New repository তৈরি করুন, যেমন quran-noor (Public)।
3) ZIP extract করে সব ফাইল repository root-এ upload/commit করুন।
4) Settings > Pages > Build and deployment-এ Deploy from a branch নির্বাচন করুন।
5) Branch: main এবং folder: /(root) নির্বাচন করে Save করুন।
6) GitHub প্রদত্ত Pages URL-এ ওয়েবসাইট খুলুন।

AdSense:
- AdSense অনুমোদন নিশ্চিত নয়; শুধু কোড বসালেই আয় শুরু হয় না।
- ওয়েবসাইটে নিজস্ব ও যথেষ্ট মানসম্মত উপকারী কনটেন্ট, কার্যকর নেভিগেশন, যোগাযোগের তথ্য ও নীতিমালা থাকা দরকার।
- Google AdSense-এ আবেদন করে সাইট অনুমোদিত হলে তাদের দেওয়া publisher ID ও ad unit code যোগ করতে হবে।
- ads.txt ফাইলের নির্দেশনা AdSense অ্যাকাউন্টে যেভাবে দেখাবে সেভাবে যোগ করবেন।
- এই প্যাকেজে কোনো ভুয়া বিজ্ঞাপন বা কাল্পনিক publisher ID যোগ করা হয়নি।

গুরুত্বপূর্ণ:
- কুরআনের অনুবাদ ও অডিও তৃতীয় পক্ষের AlQuran Cloud API থেকে আসে; API অনুপলব্ধ হলে কনটেন্ট লোড নাও হতে পারে।
- প্রকাশের আগে নিজের ইমেইল, অনুবাদ, অডিও ও সব পেজ পরীক্ষা করুন।
- privacy policy-তে ভবিষ্যৎ বিজ্ঞাপন সংক্রান্ত তথ্য দেওয়া আছে; AdSense সক্রিয় করার আগে Google-এর সর্বশেষ নীতি অনুযায়ী এটি আবার পর্যালোচনা করুন।
